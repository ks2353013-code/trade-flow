# Northern Railway Simulator — Open Rails Integration

Open Rails is the intended PC simulation foundation. Its public source is GPL-3.0 and supports routes, rolling stock, 3D cabs, signalling, AI, activities and timetable operation.

Implementation stages:
1. Pin an Open Rails source release and preserve GPL source/license notices.
2. Create a Northern Railway content pack rather than copying unlicensed third-party assets.
3. Build Delhi–Ambala route geometry, track database, OHE, signals, speed restrictions and station environments.
4. Add licensed/original WAP-5, WAP-7, WAG-7 and WAG-9 rolling stock and cab views.
5. Add timetable/activities for passenger, freight, monsoon, fog and night operations.
6. Validate signalling, braking, AI dispatching and timetable performance.
7. Package a Windows build; Android is a separate optimized client and is not a direct Open Rails binary port.

Source reference: https://github.com/openrails/openrails
