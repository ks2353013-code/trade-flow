# TradeFlow Competitive Parity / Advantage Report

## Current status

**Method:** adapted Replica methodology.

This is not a claim that TradeFlow has feature parity with every benchmark. The objective is to identify the complete job-to-be-done and then outperform on trade-specific execution.

## Strategic verdict

TradeFlow should NOT attempt literal parity with:
- Alibaba's marketplace/network scale
- IndiaMART's marketplace inventory
- Apollo's general-purpose contact database
- HubSpot's broad CRM ecosystem

Instead, build superior **trade workflow depth** across the connected journey.

## Release rule

Do not call TradeFlow “better than competitors” publicly based on this document alone.

For each major competitor, run:
1. public-source recon
2. feature matrix
3. documented review sample
4. workflow comparison
5. live TradeFlow test
6. security/tenant test
7. measured outcome comparison

The desired end state is **better than the benchmark for the specific global-trade job**, not a superficial clone.
