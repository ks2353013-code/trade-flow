# Master Admin verification review guide

Use the Business Verification Review Center only through a backend-confirmed Master Admin session.

1. Compare the legal name and identifiers with core registration evidence.
2. Confirm that the selected category matches declared activity.
3. For exporter/importer claims, review IEC evidence.
4. For manufacturers, review operating/factory and production evidence.
5. Check document validity, signature-scan status, missing evidence, and duplicate-identifier risk flags.
6. Record the checklist and internal notes without copying sensitive identifiers.
7. Request more information when evidence is incomplete.
8. Verify only a submitted or under-review application with no unresolved duplicate flag.
9. Enter a reason for rejection, suspension, or expiry and confirm the action explicitly.

“Format Validated” means structural checks only. “Document Reviewed” means a Master Admin reviewed submitted evidence. Use “Official Source Confirmed” only when an authorized source was actually consulted. Do not describe structural or document review as government verification.
