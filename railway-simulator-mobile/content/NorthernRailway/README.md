# Northern Railway content pack

This directory is reserved for original or properly licensed Northern Railway content.

Required content layers:
- Routes and track geometry
- Terrain and scenery
- Stations and platforms
- 25kV OHE
- Indian colour-light signalling
- Speed boards and kilometre posts
- WAP-5/WAP-7/WAG-7/WAG-9 rolling stock
- Passenger/freight consists
- 3D cab views and control definitions
- Timetable and activity files
- Original/appropriately licensed sound assets

Do not copy third-party assets merely because they are downloadable. Preserve each asset's license and attribution.
