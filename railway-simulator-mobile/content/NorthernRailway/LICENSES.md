# Licensing manifest

## Engine
Open Rails is GPL-3.0. Its source and license must remain available when distributing modified Open Rails software. See https://github.com/openrails/openrails and the repository LICENSE.

## Northern Railway content
All route, station, rolling-stock, cab, sound, texture and scenery assets added to this project must be original or accompanied by a license that permits redistribution and modification. No asset is considered cleared merely because it is publicly downloadable.

## Data
Operational/timetable data must be verified against an appropriate source before being presented as an exact current timetable. Build placeholders are explicitly marked where verification has not occurred.
